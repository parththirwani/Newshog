# Newshog

Newshog is an AI-assisted PR newsjacking tool. Paste a story URL, get a scored analysis, angle suggestions, pitch generation, optional deep research, and journalist-request matching.

## Features

- URL-based story analysis
- PR opportunity score with timing guidance
- angle generation
- pitch, blog post, and social post generation
- optional deep research
- journalist-request matching
- profile-based personalization
